# Plan de Revel

Chaque étape se termine par une étiquette Git (`step-N`) et des installateurs de test ; le détail de l'étape en
cours est dans `ETAPE-N.md`, les choix dans `DECISIONS.md`.

| Étape | Contenu | État |
|---|---|---|
| 0 | Squelette modulaire (crates), intégration continue sur Windows, macOS et Linux | terminée |
| 1 | Projet sur disque, import d'un projet Eleventy, génération (images AVIF/WebP), aperçu, publication SFTP et GitHub Pages, interface français/anglais | terminée |
| 2 | Éditeur visuel : canevas, calques, réglages, panneau de styles, points de rupture, textes modifiés sur place, espace de travail modulable, glisser-déposer, vues du site (Éditeur, CMS, Localisation, Paramètres) | terminée (0.2.2) |
| 3 | Contenus du CMS (champs, texte riche, collections), pages, médias, composants, blocs, langues (un dossier par langue), réglages du site (polices copiées dans le site, code ajouté, référencement), sauvegardes, synchronisation GitHub à la publication, suite du canevas, réglages lisibles | terminée (`ETAPE-3.md`) |
| 4 | Assistants IA dans Revel, quel que soit le modèle (D-31) : serveur MCP (`revel-mcp`) sur l'ordinateur (stdio et HTTP local : Claude Desktop, Claude Code, ChatGPT de bureau, Codex, LM Studio, Open WebUI avec Ollama…), réglages pour brancher chaque assistant, interface HTTP décrite en OpenAPI pour les outils sans MCP ; ni accès depuis un assistant en ligne (tunnel), ni discussion intégrée à Revel (D-44, D-45) | terminée |
| 5 | Mise en ligne directe pour les non-techniciens (demande du 16/10/2026) : bouton « Publier » en un clic, première mise en ligne guidée par hébergeur (OVHcloud, o2switch, Infomaniak, Hostinger, IONOS, GitHub Pages, autre), vérifications automatiques, contrôles avant publication, retour à la publication précédente ; noms de domaine (enregistrements DNS, vérification) ; réception des formulaires par l'hébergement — sans service extérieur ajouté par Revel (`docs/ETAPE-5.md`, D-47 à D-54) | terminée |
| 6 | Animations et interactions (dont animations Lottie exportées d'After Effects), empaquetage, mises à jour automatiques, signature du code, documentation ; en fin d'étape (demande du 16/10/2026) : dernière passe de comparaison avec Framer, Figma et Webflow (fonctions moins bien intégrées dans Revel) et passe complète d'expérience, d'interface et de direction artistique de Revel (éléments visuellement faibles à reprendre) ; installateur de la version 1.0 plus léger et soigné, au logo de Revel, sans langue de traduction livrée (D-46 ; dès la 0.5.1, D-79) ; animations prêtes à l'emploi à l'image de Framer (demande du 16/10/2026, `docs/ETAPE-6.md`, D-59) | terminée côté application (17/10/2026) ; mises à jour et signature actives dès que l'utilisateur déclare la clé et les certificats (D-77, D-09) ; recréation complète du site Alunites en dernier |
| 7 | Import depuis d'autres outils, le plus fidèle possible (D-33) : site HTML statique (dossier ou adresse), Webflow (export du code et contenus du CMS par son API), Framer (site publié lu à son adresse, pas d'export proposé par Framer), Figma (maquettes lues par son API : cadres, composants, variables, images), WordPress (contenus, médias, redirections), en plus d'Eleventy ; compatibilité maximale des animations, interactions et effets de superposition propres à chaque site (demande du 16/10/2026) | en cours (17/10/2026) : 7.1 HTML statique, 7.2 dépôt Git (D-80) ; plan : `docs/ETAPE-7.md` |
